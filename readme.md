# Retroteca

Aplicación de consola en C# para gestionar una tienda de alquiler de videojuegos retro.
Proyecto UT2 - Iniciación a la programación (SMR2ºA).

## Qué hace
- Registra un alquiler: cliente, producto, extras y recogida o entrega a domicilio.
- Calcula el importe, aplica un 10 % de descuento si el subtotal llega a 10 €, cobra y da el cambio.
- Muestra el ticket y la caja de la sesión (alquileres, recaudación, importe medio y alquiler más caro).

## Cómo ejecutarlo
1. Instalar el SDK de .NET 10.0.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar: `dotnet run`

## Notas
- Los importes se escriben con coma (por ejemplo 5,00).
- Los datos se reinician al cerrar la aplicación.
